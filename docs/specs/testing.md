# 测试与验证协议

适用于测试代码、测试配置、CI 和交付声明。叠加 [通用开发协议](<devlopment.md>) 与对应领域规范。

## 测试对象

- 测试直接引用项目实际逻辑源码，验证真实业务结果、权限和持久化状态。
- 涉及 DSH 的会话、Agent、服务、事件、插槽和生命周期时，使用当前安装版本的官方公开库或真实 DSH 运行环境。不得用接口相似的手工对象代替官方实现。
- 保留纯业务规则测试、真实数据库集成测试和真实端到端测试。测试数量与通过率不能替代有效验证。
- 不编写或保留针对 JSX 结构、组件树、样式、尺寸、颜色、视觉快照的 UI 测试；不得以测试断言覆盖用户手动调整的界面与样式。

## 禁止 Mock 与替身

- 删除所有依赖 Mock 的测试，不仅限于被测函数自身。HTTP、进程、文件系统、数据库、宿主能力和时钟等外部边界也不得用替身模拟。
- 禁止使用 vi.mock、vi.fn、vi.spyOn、stubGlobal、手工假 Context、假 Agent、RecordingRunner、假 CLI、预设 HTTP 响应或请求拦截来构造通过结果。
- 不复制生产算法作为测试实现，不伪造官方模块、服务状态机或消息事件，不新增仅供测试调用的生产导出。
- 混合测试仅保留能够独立调用真实逻辑的用例，清除其 Mock 初始化、伪宿主和无用清理代码。没有有效真实用例的测试文件直接删除。

## 真实逻辑与隔离

- 单元测试直接调用项目纯业务规则；集成测试使用项目实际模型、迁移和服务，以及所依赖的真实库。
- 数据库使用独立内存库或临时库，并执行项目真实迁移。真实数据库约束、事务失败与回滚属于实际行为验证。
- 文件和进程操作使用测试独占的临时目录；每例释放数据库、订阅、计时器与自有子进程。不得访问或修改用户真实数据库、配置、会话与凭据。
- 不读取真实平台 Token、不执行真实账号授权、不改变系统代理或全局 CLI 登录。外部条件不足时如实报告，不构造替身、不返回默认成功。
- 涉及 DSH 的版本差异必须核对官方公开类型与实现，不能通过类型断言或兼容存根掩盖。

## 端到端测试

- 必须保留 E2E。E2E 使用真实官方 DSH CLI、真实插件和真实浏览器，通过实际应用接口及持久化结果验证完整业务链路。
- 不 Mock 后端、不拦截请求填充响应、不用独立组件夹具或伪页面代替真实应用。仅校验 URL、模块能导入或页面无报错不足以证明业务通过。
- 每次运行使用独立 DSH_HOME、profile、工作目录和数据目录；不得沿用或修改当前用户环境。启动入口必须支持这些隔离参数，不能使用强制指向用户目录的 Desktop shim。
- 仅清理本次测试创建并持有的进程与目录；启动、失败和超时均须完成收尾。
- 测试自己的临时登录凭据仅用于本次授权连接，不打印 Token、含 Token 的启动 URL 或敏感日志。一次性登录凭据只兑换一次。
- CI 必须实际执行 E2E；缺少 CLI、浏览器或必要配置应明确失败，不能跳过测试后宣称通过。
- 隔离 E2E 实例不代表更新或验证了用户当前 GUI；交付时明确验证对象。

## 断言与需求边界

- 检查可观察的业务结果、权限、数据归属和持久化变化，不只检查函数被调用、模块存在或源码字符串。
- 用例标题描述对象、条件和预期结果；每例围绕实际行为，覆盖必要的成功、失败、并发、取消、归档与幂等路径。
- 不使用宽泛快照、任意容差、条件跳过或降低断言制造通过；失败不能静默变成默认成功值。
- 用户明确要求和官方协议决定业务行为。测试与需求不符时修正或删除无效测试，不扩大产品范围、不为测试修改正确业务或用户样式。
- 回归验证应能捕获实际缺陷，不重复堆积测试，也不为了可测试性引入无关架构。

## 交付与 CI

接口或数据库类型改变时先运行对应生成器，检查实际输出，不只判断退出码。代码交付依次执行：

```bash
pnpm run lint --fix
pnpm run typecheck
pnpm run test -- --run
pnpm run test:e2e
```

- E2E 使用经过核实的官方 CLI 入口；依赖和版本与 CI 保持一致。
- 推送后核对最终提交的精确 SHA，等待该提交的全部 CI 任务与 E2E 实际成功。不能用旧提交、其他分支、跳过的任务或本地单测替代 CI 结果。
- CI 失败先读实际日志并修复根因；不得删除、禁用或跳过检查来获得绿色状态。
- 交付明确区分源码完成、类型检查、真实逻辑测试、隔离 E2E、当前 GUI 与真实账号授权的验证结果。匿名网络探测仅证明当次网络可达。
- 不手改生成文件，不修改只读参考副本，不运行未经授权的本地 Build 或会间接触发构建的安装脚本；CI 按既定构建流程验证。
- 文档仅检查规则一致性、路由、链接和补丁；不以文档维护为由修改无关业务。
